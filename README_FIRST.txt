# Study Command Center v7.1 Full Static

Dashboard-only static build. No login/auth gateway. Designed for GitHub Pages / Cloudflare Pages / Netlify.

## Added in v7.1
- Policies tab
- Plans/Schedules tab
- Groups manager
- Planning History tab
- Install / Setup Status tab
- Config Generator
- Diagnostic report export
- Stronger stale device / frozen live / high ping warnings
- Better Windows + Chrome + Edge pairing overview
- Planning diagnostics
- Local persistence for rules/plans/groups/policies

## Existing features retained
- Boot diagnostics
- Lazy-loaded modules
- Worker/API/WebSocket diagnostics
- Home
- Devices
- Live grid
- about:blank live popout
- Dashboard ping / device ping / live ping
- Windows Agent v2 controls
- Chrome + Edge browser companion controls
- Planning Center
- Sessions
- Health
- Silent debugger
- Clean logs + dirty logs
- Advanced command center
- Settings

## Setup
Upload all files to GitHub repo root:
- index.html
- style.css
- config.js
- js/
- README_FIRST.txt
- CHECKS.txt

Then enable GitHub Pages and edit config.js if needed.
